# The game's models and their sources

Each folder here holds one glTF 2.0 model, copied to `Models/` next to the executable and declared in `GameModels`. A
model under CC BY 4.0 may be shipped and changed in a game sold commercially if its authors are credited as below
(in the game's credits too) and changes are marked.
