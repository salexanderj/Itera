# Generated reference

The files here list what the code holds: options, console commands, systems, tunables, replicated kinds, and save
sections. The reference tests make them from the code and fail when a file differs from what the code makes now. Never
edit them by hand: set `ITERA_WRITE_REFERENCE=1` for a run of the reference tests, look over the diff, and commit it.
The files named `engine-*` come from the engine's tests, and those named `game-*` from the game's.
